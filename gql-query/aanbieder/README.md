# Query-templates voor de aanbieder

Hier staan de query templates die de aanbieder kan gebruiken voor het raadplegen van gegevens in het Leveringsregister. De templates dienen als voorbeeld hoe de query opgebouwd moet worden. De structuur en bepaalde verplichte parameters zijn nodig om te voldoen aan de autorisatie-policies.

Ga naar [Raadplegen](/iWlz-levering/raadplegen/README.md) voor meer uitleg.
